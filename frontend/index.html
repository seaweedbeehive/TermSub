How to get an OpenAI API Key

You can get an OpenAI API key through the OpenAI Platform. A valid payment method is required, but you only pay for what you use.

  1. Navigate to OpenAI Platform and sign in with your account.
  2. Go to Settings → Billing and add a payment method.
  3. Click "API keys" in the left-hand navigation menu.
  4. Select "Create new secret key" and copy it immediately (it will not be shown again).

Note: whisper-1 and gpt-5.4-mini are billed per token / per minute of audio. Costs are typically very low for prototyping and personal projects. Always monitor your usage dashboard.

How to Use TermSub

  • Upload – drag & drop a video, audio, or .txt/.srt file (or click the upload area). Max file size is 500 MB.
  • Choose languages – pick a source language (or Auto-detect) and a target language. Type in the dropdown to search 59 languages by English or native name.
  • Enter your OpenAI API key – paste your key in the field; it is saved only in your browser.
  • Click Start – TermSub uploads the file and runs transcription, terminology analysis, and translation in the background. Monitor progress in the Activity Log.
  • Review & refine – edit extracted terms for consistency, then tweak subtitles in the timeline (edit text, split/add/remove segments, or use Find & Replace).
  • Export – download SRT, VTT, TXT, or JSON files when you are done.
